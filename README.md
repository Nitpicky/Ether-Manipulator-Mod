# Ether Manipulator

A Minecraft 1.21.1 multitool mod: a continuous left-click Beam, right-click Modes, elemental Modules and a native upgrade screen.

## Requirements

- Minecraft **1.21.1**, Java **21**
- NeoForge **21.1.265** or newer
- GeckoLib **4.9.3** or newer

Install the mod and GeckoLib on both client and server.

## Controls

- **R**: summon or put away the Manipulator
- **K**: open the upgrade screen
- **Left Alt**: Mode wheel
- **Left click**: Beam. **Right click**: charge and fire the active Mode

## Building

```sh
./gradlew build
```
